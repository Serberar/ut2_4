1. Validación con W3C Validator

Proceso

  1. Acceder al validador en validator.w3.org.
  2. Pegar el código HTML o indicar la URL del documento.
  3. Revisar los errores y advertencias devueltos.
  4. Corregir en el editor y repetir hasta obtener "Document checking completed. No errors or warnings to show."

Errores más comunes y correcciones aplicadas

Tabla 1 – Errores detectados y correcciones
Error detectado Corrección aplicada
Falta el atributo alt en imágenes Añadido alt descriptivo (o vacío si es decorativa)
Etiqueta <b> sin valor semántico Sustituida por <strong> o <em>
Atributo border en <table> Eliminado; estilos trasladados a CSS
<center> (etiqueta obsoleta) Reemplazada por text-align: center en CSS
Falta lang en <html> Añadido lang="es"

2. Evaluación de accesibilidad (Lighthouse / WAVE)

Criterios WCAG 2.1 revisados

  • Perceptible: imágenes con alt, contraste de color mínimo 4.5:1.
  • Operable: navegación completa por teclado, skip-link al contenido principal.
  • Comprensible: idioma declarado (lang="es"), etiquetas en formularios.
  • Robusto: HTML semántico y válido; ARIA solo cuando el HTML nativo no basta.

Mejoras aplicadas en esta página

  • Enlace "Saltar al contenido principal" visible al recibir foco (skip-link).
  • Todos los <img> tienen alt adecuado.
  • Navegación con aria-label para diferenciar múltiples <nav>.
  • Encabezados en orden lógico (h1 → h2 → h3).
  • Contraste de color verificado: texto principal #1e293b sobre #ffffff = ratio 16.2:1.
  • Formularios con <label> asociado mediante for/id.
  • Tablas con <caption> y scope en celdas de encabezado.

3. Mejoras para SEO técnico

Mejoras aplicadas en el <head>

  • <title> único, descriptivo y con menos de 60 caracteres.
  • meta description entre 120-160 caracteres con la palabra clave principal.
  • meta robots con index, follow.
  • link rel="canonical" para evitar contenido duplicado.
  • Etiquetas Open Graph para compartir en redes sociales.

Mejoras estructurales

  • Un solo <h1> por página con la palabra clave principal.
  • Uso de etiquetas semánticas: <header>, <main>, <section>, <footer>.
  • Atributo lang en <html> para indicar el idioma del contenido.
  • Imágenes con alt descriptivo que incluye la palabra clave cuando es relevante.
  • URLs limpias y descriptivas (estructura de carpetas semántica).
  • Carga optimizada: loading="lazy" en imágenes fuera del viewport inicial.
