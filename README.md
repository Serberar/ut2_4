# UT2 · Actividad 4 – Validación, accesibilidad y SEO

Página de ejemplo que aplica **validación W3C, accesibilidad WCAG 2.1 y SEO técnico**, y documenta el proceso. Cuarta actividad de la Unidad 2 del módulo «Lenguajes de Marcas y Sistemas de Gestión de Información» (1º DAW).

**Ver online:** https://serberar.github.io/ut2_4/

## Contenido

1. Validación con el W3C Validator.
2. Evaluación de accesibilidad con Lighthouse y WAVE.
3. Mejoras de SEO técnico: `meta description`, `canonical`, `robots` y etiquetas Open Graph.
4. Conclusiones.

## Archivos

- `index.html`: contenido.
- `estilos.css`: estilos, con colores de enlace contrastados y enlace «saltar al contenido».
